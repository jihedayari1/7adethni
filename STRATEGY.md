# Competitive strategy — Tunisian Arabizi AI

## The landscape (researched 2026-06)
- **Unifunl.io** (Tunis): conversational-commerce platform — omnichannel (IG/Messenger/WhatsApp/
  TikTok/web), autonomous order-taking, CRM, Shopify/WooCommerce. **25+ languages, general
  multilingual — NOT Tunisian-Derja-native.** Ahead on PLATFORM, weak on authentic dialect.
- Other Arabic chatbots (teammates.ai, arabot.io, arabic.ai, kommunicate, yourgpt): mostly MSA /
  Gulf dialects, shallow on Maghrebi. Crowded "Arabic chatbot" category.

## Honest verdict
- As a **CS chatbot platform**, you are behind (a model ≠ a product; they have integrations + omnichannel).
- Your ONLY defensible edge = **the most authentic Tunisian Derja/Arabizi generation**, proven
  (+84pt dialect-rate jump). Generic players sound robotic in Tunisian. Strategy must lean on THIS.

## Three paths

### A. Stay in customer-service, but niche down (hard)
Sell to a narrow segment where authentic Derja matters and generic bots fail (e.g. Tunisian
Instagram clothing/cosmetics shops, where customers banter in Arabizi). Position: "the only bot
that answers like a REAL Tunisian." Risk: still need integrations; competing on Unifunl's turf.

### B. Be the infrastructure / API layer (B2B2C)
Don't build the platform — **sell the Tunisian Arabizi model/API** to agencies, community managers,
and even platforms like Unifunl that lack a native Derja engine. You become the "Tunisian dialect
engine" others build on. Lower UI burden; harder sales motion.

### C. ⭐ Consumer Arabizi writing assistant (the "beta" extension) — RECOMMENDED
A browser extension / app that helps everyday Tunisians **write** in Arabizi: posts, replies,
captions, rewrites, translate-to-Derja. **Different market, almost no direct competitor, plays
exactly to the model's proven strength, human-in-the-loop (so the current coherence gap matters
far less — it ASSISTS, it doesn't act autonomously).**

## Why C is the smart first move
1. **Avoids Unifunl entirely** — different market (B2C everyday users, not e-commerce ops).
2. **No real competitor** — ChatGPT/Grammarly don't do natural Tunisian Arabizi; generic tools fake it.
3. **Lower risk** — assists a human; a slightly-off suggestion is fine (user edits). Autonomous CS
   with wrong prices/orders is not.
4. **Light to build** — no omnichannel, CRM, order systems. Just great text generation + simple UX.
5. **Builds the real moat: a DATA FLYWHEEL.** Users generate + correct Tunisian Arabizi → you collect
   it → the model gets better than anyone using generic LLMs → compounding advantage no competitor
   can copy without the same Tunisian user base.
6. **Brand + reputation locally**: "the first truly Tunisian AI" is a story that resonates, spreads,
   and earns trust — which you can LATER convert into the CS/API business (paths A/B) from a position
   of strength + audience + data.

## The extension — beta scope (MVP)
Form: Chrome extension (later: Android keyboard/IME). Core features:
1. **Write a post** — topic → natural Arabizi post (FB/Insta), with tone (funny / serious / promo).
2. **Reply to a message** — paste incoming → suggested Arabizi reply, tone options.
3. **Rewrite / improve** — fix, shorten, make funnier, more polite.
4. **Translate to Derja** — FR/EN/Arabic → natural Tunisian Arabizi (the model's home run).
5. **Caption** — for a photo/idea.
UX: floating button or right-click on any text field; side panel. Calls your hosted model API.

Monetization: freemium (e.g. 15 free gens/day) → cheap local subscription, and/or a B2B tier for
influencers / community managers. Keep it local-priced.

## Sequencing (recommended)
1. **Polish the model** (7B/8B + more reviewed pairs) → enough coherence for an assist tool.
2. **Ship the extension beta** to the Tunisian tech/social community; build in public; get influencers
   + community managers using it → testimonials + the data flywheel + brand.
3. **Then** monetize: consumer subscription, and upsell a **business/API tier** (paths A/B) to shops
   and agencies — now with proof, users, and the best Tunisian model on the market.

## The moat, stated plainly
Not the chatbot. The moat = **the best Tunisian Derja/Arabizi model + a data flywheel from real
users + the "Tunisian AI" brand.** Own those three and you win the niche Unifunl can't, because
they're a generic platform and you're the dialect itself.
